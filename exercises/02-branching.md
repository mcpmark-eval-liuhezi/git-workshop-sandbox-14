# Exercise 02 — Branching

In this exercise we will practice creating and working with branches, which is one of Git's most powerful features.

## Tasks
- Create a new branch with `git branch <name>` and switch to it with `git checkout <name>`
- Push your branch and open a pull request against `main` to merge it back
--life-demo a merge conflict by editing the same line in both branches, then resolve it

Remember: branches are just pointers to commits. Switching between them is instant, and you can delete a branch with `git branch -d <name>` once it is merged.
