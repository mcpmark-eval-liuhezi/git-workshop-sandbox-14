# Exercise 01 — Git Basics

This is the starting point for our hands-on Git workshop. In this exercise we will cover the core of everyday Git work:

- Initializing and armsizing a repository
- Making your first commits with clear messages
- Viewing `git log` and understanding commit history

Run `git status` after each change to see what is staged, and use `git commit -m "..."` to record your work step by step.
